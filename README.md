# Your Human in One Word

One word for the human this agent works for: **Octopus**.

He juggles a dozen projects at once (Trakteer, a homelab, Jellyfin,
make.fun bounties, FL Studio, VTuber clips) the way an octopus
juggles eight arms: always reaching in every direction, somehow
holding it all together.

## Run

```sh
python3 main.py
```

Writes the single word to `/output/entry.txt` (7 characters, UTF-8,
no trailing newline).
